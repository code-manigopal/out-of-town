# Roadmap

Solo developer with Claude Code. Dates are rough; each milestone ends with something playable.

| Milestone | Goal | Done when |
| --- | --- | --- |
| **M0 — Setup** (2 weeks) | Repo on GitHub, Git LFS, Godot 4.7 project, Claude Code working | `game/project.godot` opens; headless tests and CI green; `/story-check` runs |
| **M1 — Story pipeline** (3 weeks) | Load exported story JSON; play a scene's dialogue with subtitles and choices in-engine | Ep 1 dialogue plays from `game/data/story/p1_scenes.json`, choices branch, state saved |
| **M2 — Vertical slice: Part 1 Ep 1** (3 months) | Mani's apartment → county road drive → Tom Portons → Lakeview Motel → empty flat | 30–40 minutes playable with final-quality lighting in one area |
| **M3 — Systems** (2 months) | Journal, inspect mode, puzzles, danger, stealth basics | Ep 2 and Ep 4 core loops work in greybox |
| **M4 — Steam page** | Capsule art, trailer from the slice, wishlist page live | Page approved on Steamworks ($100 app fee) |
| **M5 — Part 1 greybox** (4 months) | All 8 episodes playable in greybox | Full Part 1 playable start to all 5 endings |
| **M6 — Demo** | Polished Ep 1 for Steam Next Fest | Demo build uploaded |
| **M7 — Part 1 content** (6+ months) | Art, animation, VO (Tanglish + English), music | Beta |
| **M8 — Part 1 release** | Launch on Steam | 1.0 |
| **M9 — Part 2** | Two playable characters, radio handler, combat | Later |
