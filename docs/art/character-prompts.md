# Character sheet prompts

For ChatGPT image generation (or any image model). Generate each character once as a **reference sheet**, then reuse the sheet as the reference image for every scene image so faces stay consistent.

## Style block (paste at the end of every prompt)
> Character reference sheet, photorealistic, cinematic game-character style like Alan Wake 2 and Hitman. Full body front view, side view and back view, plus a close-up of the face (neutral and one expression). Plain light-grey background, soft even studio light, natural skin texture, realistic proportions, no text, no logos, 16:9.
