# Shop signs

`<shop_id>.png` is the picture on each storefront's sign quad (size = (shop width - 1.3) m x 0.9 m at 300 px per metre).
The files here are **placeholder typography**, rendered by `art_source/environments/windsor/exterior/tools/make_shop_signs.py` with
SIL OFL 1.1 Google Fonts (Pacifico, Bebas Neue, Lobster, Abril Fatface, Alfa Slab One, Limelight, Righteous, Rye; see
`art_source/environments/windsor/exterior/fonts/SOURCES.md`). Replace any of them with the real picture at the same pixel size
(`docs/art/prompts-shop-signs.md` has one prompt per shop); no code change is needed. The shop names are invented.
